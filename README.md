# 智慧製造 AI Agent 專案

## 專案簡介

本專案為元智大學智慧製造課程期末報告，主要探討人工智慧（AI Agent）與機器學習技術在資料分析中的應用。

透過建立不同難度的資料集，比較機器學習模型在各種資料品質條件下的表現，分析資料噪音、缺失值及類別重疊對模型準確率的影響，並結合 AI Agent 概念進行智慧化分析與決策支援。

---

## 專案目標

- 建立不同難度的資料集進行測試
- 評估機器學習模型分類效果
- 比較 Accuracy、Precision、Recall 等指標
- 分析資料品質對模型效能的影響
- 探討 AI Agent 在智慧製造中的應用潛力

---

## 研究內容

### 簡單資料集（Simple Dataset）

- 類別界線明顯
- 幾乎沒有雜訊資料
- 分類難度低
- 模型表現接近完美

### 中等資料集（Medium Dataset）

- 存在部分雜訊
- 類別開始重疊
- 含部分缺失值
- 分類難度提升

### 困難資料集（Hard Dataset）

- 大量雜訊資料
- 類別高度重疊
- 特徵辨識度降低
- 模型效能明顯下降

---

## 分析結果

研究結果顯示：

✅ 資料品質越好，模型準確率越高

✅ 缺失值與資料雜訊會降低模型效能

✅ 類別重疊會使 Recall 顯著下降

✅ 困難資料集容易出現分類錯誤

✅ AI Agent 能協助自動化分析流程與決策支援

---

## AI Agent 流程

1. 接收資料集
2. 進行資料前處理
3. 執行機器學習模型
4. 評估模型表現
5. 產生分析結果
6. 提供決策建議

## 專案成果

本專案驗證了資料品質對機器學習模型的重要性，並展示 AI Agent 在智慧製造場域中的應用可能性。

透過自動化分析流程，可以有效提升資料分析效率，為智慧製造系統提供決策支援能力。
